KodiScript Dart SDK provides a lightweight, embeddable scripting language for Dart/Flutter applications. It runs on iOS, Android, the web, and desktop: it does not depend on `dart:mirrors`.

## Installation

Add to your `pubspec.yaml`:

<Install sdk="dart" />

Then run:

```bash
dart pub get
```

## Quick Start

```dart
import 'package:kodi_script/kodi_script.dart';

void main() {
  // Simple evaluation
  final result = KodiScript.eval('2 + 3 * 4');
  print(result); // 14.0

  // With variables
  final greeting = KodiScript.run(
    'greeting + ", " + name + "!"',
    variables: {'greeting': 'Hello', 'name': 'World'},
  );
  print(greeting.value); // "Hello, World!"
}
```

Numbers are Dart `double`s: `2 + 3 * 4` evaluates to `14.0`.

## API Reference

### `KodiScript.eval(source)`

Evaluates a script and returns the result value. Throws `KodiScriptException` on error.

```dart
final value = KodiScript.eval('10 + 5');
print(value); // 15.0
```

### `KodiScript.run(source, variables)`

Runs a script with optional variables and returns a `ScriptResult`.

```dart
final result = KodiScript.run(
  'x * 2',
  variables: {'x': 21},
);
print(result.value); // 42.0
print(result.output); // print() output
print(result.hasErrors); // false
```

### `KodiScript.builder(source)`

Creates a builder for advanced configuration.

```dart
final result = KodiScript.builder('add(2, 3)')
    .withVariable('multiplier', 10)
    .registerFunction('add', (args) =>
        (args[0] as double) + (args[1] as double))
    .execute();
```

| Method | Description |
|--------|-------------|
| `withVariable(name, value)` / `withVariables(map)` | Inject variables |
| `registerFunction(name, fn)` | Register a custom native function: `fn` receives the argument list |
| `bind(name, obj)` | Bind an object that implements `KodiBindable` |
| `withMaxOperations(n)` | Cap the number of operations |
| `withTimeout(duration)` | Cap wall-clock execution time (`Duration`) |
| `withOutput(sink)` | Route each `print()` line to a callback (still captured) |
| `withCache(enabled)` | Turn AST caching on or off (on by default) |
| `execute()` | Run and return a `ScriptResult` |

## Capturing Output

```dart
final result = KodiScript.run('''
  let items = ["apple", "banana", "cherry"]
  for (item in items) {
    print(item)
  }
''');

for (final line in result.output) {
  print(line);
}
// apple
// banana
// cherry
```

Or stream each `print()` line to a callback as it happens with `withOutput` (output is still captured in `result.output`):

```dart
final lines = <String>[];
KodiScript.builder('print("a")\nprint("b")')
    .withOutput((line) => lines.add(line))
    .execute();
// lines == ['a', 'b']
```

Without a callback, `print()` lines go to the developer log (`dart:developer`), not to stdout.

## Custom Native Functions

```dart
final result = KodiScript.builder('greet("Dart")')
    .registerFunction('greet', (args) => 'Hello, ${args[0]}!')
    .execute();

print(result.value); // "Hello, Dart!"
```

## Binding Objects

An object bound with `bind` implements `KodiBindable`: it lists the properties and methods it exposes. There is no reflection, so the same code runs on every Flutter platform.

```dart
class User implements KodiBindable {
  final String name;
  User(this.name);

  @override
  Object? getProperty(String name) => name == 'name' ? this.name : null;

  @override
  Object? callMethod(String name, List<Object?> args) {
    if (name == 'greet') return 'Hello, ${this.name}!';
    return methodNotFound;
  }
}

final result = KodiScript.builder('user.greet()')
    .bind('user', User('Alice'))
    .execute();
print(result.value); // "Hello, Alice!"
```

A method the object does not know returns `methodNotFound`, which tells the interpreter to report an unknown method. See [Extensibility](/language-guide/extensibility/) for a service example.

## Error Handling

```dart
try {
  KodiScript.eval('1 / 0');
} on KodiScriptException catch (e) {
  print('Script error: ${e.errors}');
}

// Or use ScriptResult
final result = KodiScript.run('undefined_var');
if (result.hasErrors) {
  print(result.errors);
}
```

Branch on the typed `errorKind` instead of parsing error strings:

```dart
final result = KodiScript.builder(script).withMaxOperations(1000).execute();

switch (result.errorKind) {
  case ErrorKind.none:          // success
  case ErrorKind.parse:         // syntax error
  case ErrorKind.runtime:       // bad operation, undefined variable, recursion, ...
  case ErrorKind.timeout:       // exceeded withTimeout
  case ErrorKind.maxOperations: // exceeded withMaxOperations
}
```

## Full Example

```dart
import 'package:kodi_script/kodi_script.dart';

void main() {
  final script = '''
    let factorial = fn(n) {
      if (n <= 1) {
        return 1
      }
      return n * factorial(n - 1)
    }

    let result = factorial(input)
    print("Factorial of " + toString(input) + " is " + toString(result))
    result
  ''';

  final result = KodiScript.run(script, variables: {'input': 5});

  print(result.output.first); // "Factorial of 5 is 120"
  print(result.value); // 120.0
}
```
