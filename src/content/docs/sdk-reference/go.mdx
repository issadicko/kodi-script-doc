## Quick Start

```go
package main

import (
    "fmt"
    kodi "github.com/issadicko/kodi-script-go"
)

func main() {
    result := kodi.Run(`
        let name = "World"
        print("Hello " + name)
    `, nil)

    for _, line := range result.Output {
        fmt.Println(line)
    }
}
```

`kodi.Eval(source)` is the shortest form: it returns the script's final value, or an `*kodi.EvalError` when the script fails.

```go
value, err := kodi.Eval(`2 + 3 * 4`)
// value == 14.0, err == nil
```

## Variable Injection

```go
vars := map[string]interface{}{
    "user": map[string]interface{}{
        "name": "Alice",
        "role": "admin",
    },
}

result := kodi.Run(`
    let greeting = "Hello " + user.name
    let status = user?.active ?: "offline"
    print(greeting)
`, vars)
```

## Builder

`kodi.New(source)` returns a `*Script` whose methods chain. `Execute()` runs it.

| Method | Description |
|--------|-------------|
| `WithVariables(map)` | Inject variables |
| `RegisterFunction(name, fn)` | Register a custom native function |
| `Bind(name, obj)` | Bind an object so scripts can call its methods and read its fields |
| `WithMaxOperations(n)` | Cap the number of operations |
| `WithTimeout(d)` | Cap wall-clock execution time (`time.Duration`) |
| `WithOutput(fn)` | Route each `print()` line to a callback (still captured) |
| `SilentPrint(true)` | Capture `print()` output without writing it to the console |
| `WithCache(false)` | Turn off AST caching (on by default) |
| `Execute()` | Run and return a `*Result` |

## Custom Functions

```go
script := kodi.New(`
    let result = myCustomFunc("hello")
    print(result)
`)

script.RegisterFunction("myCustomFunc", func(args ...interface{}) (interface{}, error) {
    return strings.ToUpper(args[0].(string)), nil
})

result := script.Execute()
```

Numbers arrive as `float64`. Returning a non-nil `error` raises a runtime error in the script, which `try` / `catch` can handle.

## Result & Error Handling

`Execute()` returns a `*Result`. Branch on the typed `Kind` field instead of parsing error strings:

```go
type Result struct {
    Value  interface{}
    Output []string
    Errors []string
    Err    error     // first underlying error (nil on success)
    Kind   ErrorKind // ErrorKindNone on success
}
```

```go
result := kodi.New(script).
    WithMaxOperations(1000).
    Execute()

switch result.Kind {
case kodi.ErrorKindNone:
    // success: use result.Value / result.Output
case kodi.ErrorKindParse:
    // syntax error
case kodi.ErrorKindRuntime:
    // bad operation, undefined variable, recursion guard, ...
case kodi.ErrorKindTimeout:
    // exceeded WithTimeout
case kodi.ErrorKindMaxOperations:
    // exceeded WithMaxOperations
}
```

You can also match the underlying error with `errors.Is`:

```go
if errors.Is(result.Err, kodi.ErrTimeout) {
    // ...
}
```

`kodi.ErrMaxOperationsExceeded` covers the operation limit the same way.

## Streaming Output

Route each `print()` line to a callback as it happens with `WithOutput` (output is still captured in `result.Output`):

```go
result := kodi.New(`print("a") print("b")`).
    WithOutput(func(line string) {
        fmt.Println("got:", line)
    }).
    Execute()
```

By default `print()` also writes to the console. Add `SilentPrint(true)` to capture only.

## Object Binding

Expose an entire Go object to scripts with `Bind`, so their methods and fields are callable directly:

```go
script := kodi.New(`print(service.Greet("World"))`)
script.Bind("service", &Greeter{})
result := script.Execute()
```

Scripts use the exported Go names as written (`Greet`, `Name`). See [Extensibility](/language-guide/extensibility/) for the full pattern.
