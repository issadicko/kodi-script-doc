KodiScript provides native SDKs for seamless integration with your applications across multiple platforms. The language is the same in all of them: a script that runs in one SDK prints the same output in the others.

## API at a Glance

The host APIs follow each language's conventions, but the same operations exist everywhere:

| | Go | Kotlin | TypeScript | Dart | PHP |
|---|---|---|---|---|---|
| Run a script | `kodi.Run(src, vars)` | `KodiScript.run(src, vars)` | `KodiScript.run(src, vars)` | `KodiScript.run(src, variables:)` | `KodiScript::run($src, $vars)` |
| Evaluate to a value | `kodi.Eval(src)` | `KodiScript.eval(src)` | n/a | `KodiScript.eval(src)` | `KodiScript::eval($src)` |
| Builder | `kodi.New(src)` | `KodiScript.builder(src)` | `KodiScript.builder(src)` | `KodiScript.builder(src)` | `KodiScript::builder($src)` |
| Inject variables | `WithVariables` | `withVariable(s)` | `withVariable(s)` | `withVariable(s)` | `withVariable(s)` |
| Custom function | `RegisterFunction` | `registerFunction` | `registerFunction` | `registerFunction` | `registerFunction` |
| Bind an object | `Bind` | `bind` | `bind` | `bind` (`KodiBindable`) | `bind` |
| Operation limit | `WithMaxOperations` | `withMaxOperations` | `withMaxOperations` | `withMaxOperations` | `withMaxOperations` |
| Timeout | `WithTimeout(duration)` | `withTimeout(ms)` | `withTimeout(ms)` | `withTimeout(Duration)` | `withTimeout(ms)` |
| Output callback | `WithOutput` | `withOutput` | `withOutput` | `withOutput` | `withOutput` |
| Error kind | `result.Kind` | `result.errorKind` | `result.errorKind` | `result.errorKind` | `$result->kind` |

Every `print()` line is captured in the result's `output` list. Go, Kotlin, and TypeScript also write it to the console unless you silence it; Dart sends it to the developer log and PHP only captures it.
