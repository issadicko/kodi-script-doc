## Embed it in your app

Hand a script its data, give it the host functions you choose, cap what it may spend, and read the result. Each SDK follows its own language's conventions:

<Tabs syncKey="sdk">
  <TabItem label="Go">
```go
result := kodi.New(`
    let discount = customer.tier == "gold" ? 20 : 5
    notify(customer.email, "Your discount: " + discount + "%")
    return discount
`).
    WithVariables(map[string]interface{}{
        "customer": map[string]interface{}{"tier": "gold", "email": "awa@example.com"},
    }).
    RegisterFunction("notify", func(args ...interface{}) (interface{}, error) {
        fmt.Printf("-> %v: %v\n", args[0], args[1])
        return true, nil
    }).
    WithMaxOperations(10000).
    WithTimeout(time.Second).
    Execute()

if result.Kind != kodi.ErrorKindNone {
    log.Println("script failed:", result.Errors)
    return
}
fmt.Println(result.Value) // 20
```
  </TabItem>
  <TabItem label="Kotlin">
```kotlin
val result = KodiScript.builder("""
    let discount = customer.tier == "gold" ? 20 : 5
    notify(customer.email, "Your discount: " + discount + "%")
    return discount
""")
    .withVariable("customer", mapOf("tier" to "gold", "email" to "awa@example.com"))
    .registerFunction("notify") { args ->
        println("-> ${args[0]}: ${args[1]}")
        true
    }
    .withMaxOperations(10_000)
    .withTimeout(1_000)
    .execute()

if (result.errorKind != ErrorKind.NONE) {
    println("script failed: ${result.errors}")
    return
}
println(result.value) // 20.0
```

```typescript
const result = KodiScript.builder(`
    let discount = customer.tier == "gold" ? 20 : 5
    notify(customer.email, "Your discount: " + discount + "%")
    return discount
`)
  .withVariable('customer', { tier: 'gold', email: 'awa@example.com' })
  .registerFunction('notify', (to, message) => {
    console.log(`-> ${to}: ${message}`);
    return true;
  })
  .withMaxOperations(10_000)
  .withTimeout(1_000)
  .execute();

if (result.errorKind !== 'none') {
  console.error('script failed:', result.errors);
} else {
  console.log(result.value); // 20
}
```

```dart
final result = KodiScript.builder('''
    let discount = customer.tier == "gold" ? 20 : 5
    notify(customer.email, "Your discount: " + discount + "%")
    return discount
''')
    .withVariable('customer', {'tier': 'gold', 'email': 'awa@example.com'})
    .registerFunction('notify', (args) {
      print('-> ${args[0]}: ${args[1]}');
      return true;
    })
    .withMaxOperations(10000)
    .withTimeout(Duration(seconds: 1))
    .execute();

if (result.errorKind != ErrorKind.none) {
  print('script failed: ${result.errors}');
  return;
}
print(result.value); // 20.0
```

```php
$result = KodiScript::builder('
    let discount = customer.tier == "gold" ? 20 : 5
    notify(customer.email, "Your discount: " + discount + "%")
    return discount
')
    ->withVariable('customer', ['tier' => 'gold', 'email' => 'awa@example.com'])
    ->registerFunction('notify', function ($to, $message) {
        echo "-> $to: $message\n";
        return true;
    })
    ->withMaxOperations(10000)
    ->withTimeout(1000)
    ->execute();

if ($result->kind !== ErrorKind::None) {
    echo 'script failed: ', implode('; ', $result->errors), "\n";
    return;
}
echo $result->value, "\n"; // 20
```

## What people build with it

- **Workflow engines**: let users define custom automation logic.
- **Rule-based systems**: configurable business rules.
- **Template processing**: dynamic content generation.
- **Game scripting**: modding and custom game logic.
- **API transformations**: transform data between services.
